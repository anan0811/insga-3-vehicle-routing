────────────────────────────────────────────────────────────────────────────────
4. 所提演算法：HNSGA-III
────────────────────────────────────────────────────────────────────────────────

4.1 概述
────────

本研究提出混合式非支配排序遺傳演算法第三代（HNSGA-III）以求解
2E-MD-MD-MP-CVRP-SPD。HNSGA-III 以標準 NSGA-III 參考點框架
（Deb & Jain, 2014）為基礎，針對第 1.3 節所識別的限制導入四項改進：

  （1）最近鄰域（NN）初始化：建構具地理結構的初始解，取代隨機排列方式；
  （2）混合突變：結合三點反轉與二點交換運算子，平衡探索與開發；
  （3）嵌入式 2-opt 區域搜尋：每代對所有子代個體執行，快速改善路線品質；
  （4）停滯觸發式變動鄰域搜尋（VNS）：採用交換與重插運算子，於收斂停滯時
        跳脫局部最優解。

演算法作用於第二階段（SE）路徑規劃層，負責各衛星站—時段區塊內的顧客指派
與服務序列決策。第一階段（FE）倉庫至衛星站的路徑，則在 SE 路徑確定後以
Gurobi MILP 求解器精確求解。

整體框架示意圖見圖 X（流程圖待補）。


4.2 解的編碼方式
────────────────

每條染色體代表特定衛星站在特定時段（上午或下午）所服務顧客 ID 的排列。
採用整數編碼：長度為 n 的染色體為序列 [c_1, c_2, ..., c_n]，每個 c_i
為唯一的顧客識別碼。車輛分隔點在解碼時由容量約束隱式決定：序列由左至右
掃描，每當累計需求超過 SE 車輛容量（400 單位）時，即開始一條新路線。

對於具有 n_s 個衛星站、每日兩個時段的問題，演算法維護 2·n_s 個獨立族群，
每個族群大小為 N_pop = 30。表 X 列出所有實驗的參數設定。

  表 X. 演算法參數設定
  ─────────────────────────────────────────────────────────────────────
  參數                                  設定值
  ─────────────────────────────────────────────────────────────────────
  族群大小（N_pop）                     30
  演化代數                              1,000
  交叉機率（cp）
    — 案例 1–10（50 位顧客）            0.70
    — 案例 11–20（80 位顧客）           0.55
  突變機率（mp）
    — 案例 1–10（50 位顧客）            0.70
    — 案例 11–20（80 位顧客）           0.80
  SE 車輛容量                           400 kg
  SE 車輛速度                           50 km/h
  FE 車輛容量                           4,000 kg
  停滯閾值（VNS 觸發代數 τ）            5 代
  每案例獨立執行次數                    10
  ─────────────────────────────────────────────────────────────────────


4.3 族群初始化：最近鄰域啟發式
────────────────────────────────

標準 NSGA-III 以隨機打亂顧客序列的方式初始化族群，忽視地理結構並產生
低品質的起始解。HNSGA-III 改採最近鄰域（NN）初始化策略，改良自
Li et al.（2025）的方法。

對族群中的每個個體，隨機選取一位顧客作為起始點，再依序加入最近未訪問
顧客（以座標空間的歐幾里得距離計算），直到所有顧客均被訪問，形成一條
NN 路線。由於每個個體採用不同的隨機起點，N_pop 個個體共同覆蓋多元的
地理入口，同時各自保持局部鄰近性——此特性是純隨機初始化無法兼顧的品質
與多樣性平衡。

若 NN 程序產生過多重複序列（顧客數量少時的風險），演算法回退至隨機打亂
以補足剩餘族群空位。

NN 初始化程序整理為演算法 1：

  演算法 1：單一族群的 NN 初始化
  ────────────────────────────────────────────────────────────────
  輸入 : 顧客集合 C、座標查找表 coord、目標族群大小 N_pop
  輸出 : 初始族群 P
  ────────────────────────────────────────────────────────────────
  P ← ∅
  attempts ← 0
  while |P| < N_pop and attempts < 30·N_pop do
      start ← 從 C 中隨機選取一位顧客
      seq   ← [start]
      unvisited ← C \ {start}
      while unvisited ≠ ∅ do
          next ← argmin_{u ∈ unvisited} dist(seq.last, u)
          seq.append(next);  unvisited ← unvisited \ {next}
      end while
      if seq ∉ P then  P ← P ∪ {seq}  end if
      attempts ← attempts + 1
  end while
  while |P| < N_pop do  P ← P ∪ {random_shuffle(C)}  end while
  return P
  ────────────────────────────────────────────────────────────────


4.4 交叉運算子
──────────────

以機率 cp 套用基於順序的交叉算子（Order-Based Crossover，OBX）。
給定兩條親代染色體 p_1 與 p_2：

  （1）從 p_1 中隨機選取連續區段 [a, b]。
  （2）將 p_1 的 a 至 b 位置直接複製至子代 c_1 的相同位置。
  （3）以 p_2 中顧客的出現順序填入 c_1 的其餘位置，跳過已放置者。
  （4）對稱地互換 p_1 與 p_2 的角色，生成 c_2。

OBX 保留兩親代的相對排序資訊，同時確保子代為有效排列（無重複或缺漏顧客）。
交叉後施行排列修復步驟，以修正二階路徑結構所導致的索引偏差。


4.5 混合突變運算子
──────────────────

為平衡大幅度結構擾動與細粒度區域精煉，HNSGA-III 採用結合兩種互補運算子
的混合突變策略，觸發突變（機率 mp）時以等機率（各 50%）選擇其一：

  （a）三點反轉（探索）：
      隨機選取三個相異位置 i < j < k，將 i 至 k 之間的子序列反轉。此運算
      子產生巨觀層次的結構變化，有助於逃脫深層局部最優解。

      反轉前：[..., c_i, c_{i+1}, ..., c_k, ...]
      反轉後：[..., c_k, c_{k-1}, ..., c_i, ...]

  （b）二點交換（開發）：
      隨機選取兩個相異位置 a 與 b，互換兩位置的顧客。此操作產生微小的
      局部變化，適合細粒度的鄰域精煉。

      交換前：[..., c_a, ..., c_b, ...]
      交換後：[..., c_b, ..., c_a, ...]

雙運算子設計使演算法在搜尋初期自然呈現較大的擾動（此時三點反轉更有效），
後期則以精準調整為主（此時二點交換已足夠），且無需任何自適應排程機制。


4.6 選擇：NSGA-III 參考點框架
──────────────────────────────

交叉與突變完成後，以 NSGA-III 選擇程序（Deb & Jain, 2014）將親代與子代
合併池縮減至 N_pop 個個體：

  （1）非支配排序：以 Pareto 支配關係將所有個體劃分為前緣
        F_1, F_2, ...。
  （2）依等級順序納入前緣至下一代，直到下一個前緣將使族群超過 N_pop 為止。
  （3）對最後一個（關鍵）前緣，使用均勻分佈於三目標空間規格化超平面上的
        參考點，優先選取與覆蓋不足參考點相關聯的個體（龕位機制），以最大化
        覆蓋範圍。

此機制在三目標 Pareto 前緣（成本、車輛數、碳排放）上明確維持分佈良好的
非支配解集合，避免 NSGA-II 在高維目標空間中發生的擁擠崩潰問題。


4.7 嵌入式 2-opt 區域搜尋
──────────────────────────

子代池由交叉與突變產生後，HNSGA-III 在 NSGA-III 選擇步驟前對每個子代
個體施行 2-opt 區域搜尋。針對每個子代：

  （1）依 SE 容量約束將染色體解碼為一組車輛路線。
  （2）隨機選取其中一條路線。
  （3）在該路線中選取兩個位置 a < b。
  （4）反轉 a 至 b 之間的子序列。
  （5）若改善後的個體不是現有個體的重複，且嚴格具有更低成本，則取代原個體。

對所有子代施行 2-opt（而非如 Li et al.（2025）僅對精英個體施行）確保每個
新生成的解在參與選擇前均接受至少一輪路線層次改善，提升候選池的平均品質，
且不引入每代完整 VNS 的額外負擔。


4.8 停滯觸發式變動鄰域搜尋
────────────────────────────

當 2-opt 區域搜尋連續多代無法改善最佳解時，搜尋很可能已陷入 2-opt 鄰域的
局部最優解。HNSGA-III 透過每個衛星站—時段區塊各自維護的停滯計數器偵測此
狀況：每代最佳個體成本未改善時計數器加一，有所改善時歸零。

當計數器達到停滯閾值（τ = 5 代）時，HNSGA-III 對當前最佳個體執行兩步驟 VNS：

  步驟 1 — 交換（Exchange）：在同一路線中隨機選取兩位顧客並互換位置，
  探索與 2-opt 不重疊的鄰域。

  步驟 2 — 重插（Relocate）：從路線中移除一位顧客，重新插入同一路線的
  不同位置，可解除陷入高成本子序列的困境。

若任一運算子產生嚴格更優且非重複的解，則取代當前最佳解，停滯計數器歸零。
此針對性應用方式（僅作用於最佳個體、僅在停滯時觸發）避免了過度開發對
族群多樣性的損害。


4.9 完整演算法
──────────────

演算法 2 呈現完整的 HNSGA-III 流程。

  演算法 2：HNSGA-III for 2E-MD-MD-MP-CVRP-SPD
  ────────────────────────────────────────────────────────────────────────
  輸入 : 案例資料、參數（N_pop, cp, mp, τ, num_gen）
  輸出 : 各衛星站—時段的最佳 SE 路線、FE 成本
  ────────────────────────────────────────────────────────────────────────
  1.  以 K-Means 將顧客群集至各衛星站
  2.  將顧客依時段分配至上午 / 下午
  3.  對每個衛星站 s 與時段 t：
  4.      P_{s,t} ← NN_Initialize(customers_{s,t}, N_pop)    // §4.3
  5.  stag_{s,t} ← 0  （對所有 s, t）
  6.  for gen = 1 to num_gen do
  7.      for 每個族群 P_{s,t} do
  8.          best_before ← P_{s,t} 中的最低成本
  9.          // 交叉
  10.         if rand() < cp then
  11.             offspring ← OBX(P_{s,t})                    // §4.4
  12.         // 突變
  13.         offspring ← offspring ∪ HybridMutate(P_{s,t}, mp)  // §4.5
  14.         // 對所有子代執行 2-opt
  15.         offspring ← 2-opt(offspring)                    // §4.7
  16.         // NSGA-III 選擇
  17.         P_{s,t} ← NSGA3_Select(P_{s,t} ∪ offspring, N_pop)  // §4.6
  18.         best_after ← P_{s,t} 中的最低成本
  19.         // 停滯追蹤
  20.         if best_after < best_before then
  21.             stag_{s,t} ← 0
  22.         else
  23.             stag_{s,t} ← stag_{s,t} + 1
  24.         if stag_{s,t} ≥ τ then
  25.             P_{s,t} ← VNS(P_{s,t})                      // §4.8
  26.             stag_{s,t} ← 0
  27.         end if
  28.     end for
  29. end for
  30. 從各 P_{s,t} 中提取最佳解
  31. 依 SE 路線計算各衛星站需求量
  32. FE_cost ← Gurobi_MILP(depots, satellites, demands)
  33. return SE 路線、FE_cost
  ────────────────────────────────────────────────────────────────────────
