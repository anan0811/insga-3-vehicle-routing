3. 問題描述與數學模型
================================================================================

3.1 問題描述
────────────

本研究探討的 2E-MD-MD-MP-CVRP-SPD 是一個多目標物流最佳化問題，定義於包含
多個倉庫（Depot）、多個衛星站（Satellite）與多個顧客（Customer）的二層配送
網路中。在第一階段（First Echelon，FE），大型貨車負責將整合貨物從倉庫運送
至衛星站；在第二階段（Second Echelon，SE），較小型的配送車輛從衛星站出發，
在同一路線中同時執行送貨與取貨任務（同取同送）。規劃期跨越多個日期（以 t∈T
為索引），且每日劃分為多個服務時段（以 p∈P 為索引，例如上午與下午），顧客
需求隨日期與時段而變動。

系統運作流程如下：
  (i)  每日透過 K-均值預處理將顧客分群至各衛星站，每個群集定義該時段的獨立
       SE 子問題。
  (ii) 針對每個衛星站 s 與時段 p，HNSGA-III 決定服務所分配顧客的 SE 車輛
       路線，同時滿足容量與流量約束。
  (iii) SE 路線確定後，計算各衛星站所需的總配送與取貨量，傳遞給 Gurobi MILP
        求解器，精確最佳化 FE 路徑（倉庫至衛星站的運輸）。

同時最小化三個目標：
  f1：總運輸成本（FE 運輸成本 + SE 運輸成本 + 軟性時間窗懲罰成本）
  f2：所有日期與時段中派遣的總車輛數（FE 貨車 + SE 車輛）
  f3：兩個層次的總碳排放量，以 MEET 模型計算


3.2 假設條件
────────────

以下假設確保數學模型的可處理性並與實際城市物流情境保持一致：

  （1）顧客退回的取貨物品暫存於服務衛星站，再統一送回倉庫。
  （2）每位顧客在每日每時段均有服務時間窗 [a_i^{t,p}, b_i^{t,p}]。車輛不
       必嚴格遵守此時間窗，但提早或延遲到達將產生相應的懲罰成本。
  （3）規劃期橫跨多個運營日，每日劃分為多個時段；顧客可能在不同日期出現於
       不同位置。
  （4）各日各時段的顧客位置、配送需求量與取貨需求量均為已知。
  （5）每座倉庫的庫存容量足以滿足所有顧客需求。
  （6）衛星站不受吞吐量容量限制。
  （7）任何 SE 車輛路線上的總載重（配送量 + 取貨量）不得超過車輛最大容量 Q_SE。
  （8）SE 車輛路線必須從同一衛星站出發並返回。
  （9）每位顧客的配送與取貨作業由同一輛車在同一次拜訪中同時完成。
  （10）SE 車輛在單次路線中不能服務不同衛星站的顧客。
  （11）所有 FE 貨車均質，最大容量為 Q_FE；任何貨車均可服務任意倉庫至衛星站
        的路段。
  （12）所有 SE 車輛均質，最大容量為 Q_SE；SE 車輛以固定速度 v_SE = 50 km/h
        行駛。

3.4 數學模型
────────────

3.4.1 目標函數
──────────────

（f1）最小化總成本

總成本 f1 由兩個分量構成：FE 運輸成本 C_FE 與 SE 運輸及懲罰成本 C_SE。

FE 運輸成本包含距離比例項（單位運費 c_FE = 0.2 $/km）與每台貨車的固定派遣
成本（F_r = 80 $ / 台）：

  C_FE = Σ_{d∈D} Σ_{s∈N_FE} Σ_{r∈K_FE} Σ_{t∈T}  y_ds^{r,t} · L_ds · c_FE
         + Σ_{r∈K_FE} Σ_{t∈T}  δ_r^{FE,t} · F_r                          (1)

其中 c_FE = 0.2 $/km，F_r = 80 $。

SE 成本由距離比例運費（單位運費 c_SE = 0.05 $/km）與軟性時間窗懲罰兩部分
構成：

  C_SE = Σ_{i,j∈N_SE} Σ_{k∈K_SE} Σ_{s∈S} Σ_{t∈T} Σ_{p∈P}
           x_ij^{k,s,t,p} · L_ij · c_SE
         + Σ_{i∈C} Σ_{k∈K_SE} Σ_{s∈S} Σ_{t∈T} Σ_{p∈P}
           [ξ_e · max(a_i^{t,p} − A_i^{k,s,t,p}, 0)
            + ξ_l · max(A_i^{k,s,t,p} − b_i^{t,p}, 0)]                    (2)

其中 c_SE = 0.05 $/km；ξ_e = ξ_l = 0.2 $/分鐘（分別為提早與延遲到達的懲罰
係數）；a_i^{t,p}、b_i^{t,p} 分別為顧客 i 在第 t 日第 p 時段的最早與最晚
允許服務時間；A_i^{k,s,t,p} 為 SE 車輛 k 抵達顧客 i 的時刻。
上午時段車輛於 540 分鐘（09:00）從衛星站出發；下午時段於 720 分鐘（12:00）
出發。

  最小化  f1 = C_FE + C_SE                                                  (3)


（f2）最小化總車輛派遣數

  最小化  f2 = Σ_{t∈T} Σ_{p∈P} (Σ_{r∈K_FE} δ_r^{FE,t} + Σ_{k∈K_SE} δ_k^{SE,t,p})  (4)

其中 δ_r^{FE,t} = 1 表示 FE 貨車 r 在第 t 日被派遣，δ_k^{SE,t,p} = 1 表示
SE 車輛 k 在第 t 日第 p 時段被派遣。


（f3）最小化總碳排放量

採用 MEET 模型（Hickman et al., 1999）計算車輛碳排放。對 3.5 噸廂式卡車以
速度 v（km/h）行駛，基礎排放率函數 φ(v) 與載重修正函數 ψ(v) 依據 MEET 報
告（Hickman et al., 1999，表 A10 與 A14）取用如下：

  φ(v) = 110 + 0.000375 · v³ + 8702/v    （g CO₂/km）                    (5)
  ψ(v) = 1.27 − 0.00235 · v − 1.33/v                                      (6)

單位距離碳排放量為 φ(v) · ψ(v) / 1000（kg CO₂/km），不考慮道路坡度（城市
平坦地形假設）。SE 車輛以固定速度 v_SE = 50 km/h 行駛，兩函數退化為常數：

  φ(50) = 110 + 0.000375 × 125000 + 8702/50 = 330.915 g/km
  ψ(50) = 1.27 − 0.00235 × 50 − 1.33/50 = 1.1259
  e_SE  = 330.915 × 1.1259 / 1000 ≈ 0.3726 kg CO₂/km

FE 貨車按行駛速度 v_FE 逐次計算 e_FE(v_FE) = φ(v_FE) · ψ(v_FE) / 1000。

  E_SE = Σ_{i,j∈N_SE} Σ_{k∈K_SE} Σ_{s∈S} Σ_{t∈T} Σ_{p∈P}
           x_ij^{k,s,t,p} · L_ij · e_SE                                    (7)

  E_FE = Σ_{(d,s)∈FE路段} Σ_{r∈K_FE} Σ_{t∈T}
           y_ds^{r,t} · L_ds · e_FE(v_FE)                                  (8)

  最小化  f3 = E_SE + E_FE                                                  (9)


3.4.2 第一階段（FE）約束
──────────────────────────

（C1）衛星站服務覆蓋：啟用的衛星站必須有至少一輛 FE 貨車到訪：

  Σ_{d∈D} Σ_{r∈K_FE} y_ds^{r,t} ≥ z_s^{t,p},   ∀s∈S, t∈T, p∈P           (11)

（C2）FE 貨車流量守恆（進入衛星站的車輛必須離開）：

  Σ_{d∈D,s∈S} y_ds^{r,t} − Σ_{s∈S,d∈D} y_sd^{r,t} = 0,  ∀r∈K_FE, t∈T  (12)

（C3）FE 車輛容量（簡化同取同送版本）：

  Σ_{d∈D,s∈S} y_ds^{r,t} · (DD_s^t + DP_s^t) ≤ Q_FE,  ∀r∈K_FE, t∈T   (13)

（C4）FE 路線貨運流量平衡（支援消除子路徑）：

  f_ds^{r,t} ≥ 0,   ∀d∈D, s∈S, r∈K_FE, t∈T                              (14)

  衛星站 s 的貨流平衡：
  Σ_{d∈D} f_ds^{r,t} − Σ_{d∈D} f_sd^{r,t} = y_ds^{r,t} · (DD_s^t + DP_s^t)  (15)

（C5）衛星站啟用連結：衛星站 s 僅在有 FE 貨車到訪時才能啟用：

  z_s^{t,p} ≤ Σ_{d∈D} Σ_{r∈K_FE} y_ds^{r,t},   ∀s∈S, t∈T, p∈P          (16)

（C6）FE 貨車從倉庫 d 出發時刻 ST_{dr}^t 須在倉庫時間窗 [a_d, b_d] 內：

  a_d · Σ_{s∈S} y_ds^{r,t} ≤ ST_{dr}^t ≤ b_d · Σ_{s∈S} y_ds^{r,t},
                                               ∀d∈D, r∈K_FE, t∈T         (17)

（C7）FE 抵達衛星站時刻與出發時刻一致（大M約束）：

  ST_{dr}^t + TT_{ds} − M(1−y_ds^{r,t}) ≤ VT_{sr}^t
             ≤ ST_{dr}^t + TT_{ds} + M(1−y_ds^{r,t}),
                                    ∀d∈D, s∈S, r∈K_FE, t∈T              (18)

  TT_{ds} 為從倉庫 d 至衛星站 s 的行駛時間，M 為足夠大的常數。

（C8）二元與非負域定義：

  y_ds^{r,t} ∈ {0,1},     ∀d∈D, s∈S, r∈K_FE, t∈T                         (19)
  f_ds^{r,t} ≥ 0,          ∀d∈D, s∈S, r∈K_FE, t∈T                        (20)
  z_s^{t,p} ∈ {0,1},       ∀s∈S, t∈T, p∈P                                (21)


3.4.3 第二階段（SE）約束
──────────────────────────

（C9）每位顧客 i 在每日每時段恰好被服務一次：

  Σ_{j∈N_SE} Σ_{k∈K_SE} x_ij^{k,s,t,p} = 1,   ∀i∈C, s∈S, t∈T, p∈P   (22)

（C10）SE 車輛各節點流量守恆：

  Σ_{j∈N_SE} x_ij^{k,s,t,p} − Σ_{j∈N_SE} x_ji^{k,s,t,p} = 0,
                                 ∀i∈N_SE, k∈K_SE, s∈S, t∈T, p∈P        (23)

（C11）SE 車輛容量（簡化同取同送版本）：路線上所有顧客的配送量與取貨量之和
       不得超過 Q_SE：

  Σ_{i∈C, j∈N_SE} x_ij^{k,s,t,p} · (DD_i^{t,p} + DP_i^{t,p}) ≤ Q_SE,
                                         ∀k∈K_SE, s∈S, t∈T, p∈P        (24)

（C12）SE 車輛路線必須從同一衛星站出發並返回：

  Σ_{j∈C} x_{sj}^{k,s,t,p} = Σ_{j∈C} x_{js}^{k,s,t,p} ≤ 1,
                                         ∀k∈K_SE, s∈S, t∈T, p∈P        (25)

（C13）消除子路徑（MTZ 輔助變數 u）：

  u_i^{k,s,t,p} − u_j^{k,s,t,p} + Q_SE · x_ij^{k,s,t,p} ≤ Q_SE − DD_j^{t,p},
                                   ∀i,j∈C, k∈K_SE, s∈S, t∈T, p∈P      (26)

  DD_i^{t,p} ≤ u_i^{k,s,t,p} ≤ Q_SE,  ∀i∈C, k∈K_SE, s∈S, t∈T, p∈P   (27)

（C14）SE 車輛抵達顧客時刻（時間一致性）：

  A_j^{k,s,t,p} ≥ A_i^{k,s,t,p} + L_ij / v_SE
                   − M · (1 − x_ij^{k,s,t,p}),
                                   ∀i,j∈C, k∈K_SE, s∈S, t∈T, p∈P      (28)

（C15）衛星站對 SE 車輛的出發時間窗 [a_s^{t,p}, b_s^{t,p}]：

  a_s^{t,p} · Σ_{j∈C} x_{sj}^{k,s,t,p} ≤ A_s^{k,s,t,p}
              ≤ b_s^{t,p} · Σ_{j∈C} x_{sj}^{k,s,t,p},
                                         ∀k∈K_SE, s∈S, t∈T, p∈P        (29)

（C16）二元與非負域定義：

  x_ij^{k,s,t,p} ∈ {0,1},    ∀i,j∈N_SE, k∈K_SE, s∈S, t∈T, p∈P        (30)
  u_i^{k,s,t,p} ≥ 0,          ∀i∈C, k∈K_SE, s∈S, t∈T, p∈P            (31)
  A_i^{k,s,t,p} ≥ 0,          ∀i∈N_SE, k∈K_SE, s∈S, t∈T, p∈P         (32)


3.5 模型總結
────────────

完整建模如下：

  最小化  { f1, f2, f3 }   受限於  (11)–(32)

表 2 總結各約束的功能：

  約束式    功能
  ──────────────────────────────────────────────────────────────────────────
  (11)      衛星站服務覆蓋
  (12)      FE 流量守恆
  (13)      FE 車輛容量（配送 + 取貨 ≤ Q_FE）
  (14)–(15) FE 貨流平衡（消除子路徑輔助）
  (16)      衛星站啟用連結
  (17)      FE 倉庫時間窗
  (18)      FE 行駛時間一致性（倉庫 → 衛星站）
  (19)–(21) FE 二元/非負域
  (22)      SE 顧客覆蓋（每位顧客恰好服務一次）
  (23)      SE 流量守恆
  (24)      SE 車輛容量（總配送 + 取貨 ≤ Q_SE）
  (25)      SE 路線閉合（從同一衛星站出發並返回）
  (26)–(27) SE 消除子路徑（MTZ）
  (28)      SE 抵達時刻一致性
  (29)      衛星站對 SE 出發時間窗
  (30)–(32) SE 二元/非負域

本問題是 NP-hard 問題：即使是單層次 CVRP 也是 NP-hard，而我們的建模加上了
二階結構、多日多期規劃以及同取同送需求。對實務規模算例（50–80 位顧客、
2–3 個衛星站、2 個時段），整個模型的精確 MILP 求解在計算上不可行。因此，
本研究採用第四章所述的混合分解方法：HNSGA-III 求解 SE 路徑問題，Gurobi MILP
在 SE 解確定後精確求解 FE 路徑。
